TERMINAL HELPER
Helpful terminal suggestions, with one switch to turn them off.

INSTALLING THE FREE BETA
The free beta is ad-hoc signed, without Developer ID or Apple notarization. Download only from the project's published GitHub release and verify its checksum. Open the disk image, drag Terminal Helper to Applications, then open the app from Applications.

If macOS says the developer cannot be verified or Apple cannot check the app, and you are certain that this download is trustworthy and unmodified, follow Apple's per-app process: after trying to open the app, go to System Settings > Privacy & Security > Open Anyway, then confirm Open. This creates an exception for this app; do not disable Gatekeeper globally or remove quarantine. Do not override a warning that the app is damaged or will harm your computer.

Apple's instructions: https://support.apple.com/102445

GET STARTED
1. In Settings, choose Install shell integration.
2. Choose Use Home folder for a standard zsh setup. If you configured ZDOTDIR, choose that folder instead. The app remembers the folder after a successful installation for repair and uninstall. A failed operation keeps the previous successful choice. Uninstall clears this preference.
3. Open a new terminal window. Existing shells need restarting to load the integration.
4. Turn on Enable suggestions from Settings or the menu-bar icon.

USING SUGGESTIONS
Press Tab to request a compact completion list. The current choice is reverse-highlighted. Use arrow keys to move through the list (including rows beyond the visible area), Enter to insert the selected text, or Escape to cancel. Accepting edits the command line only. Press Enter again after the list closes to execute deliberately.

Files, directories, executable names, and your existing command completions are supported. Typo corrections are marked separately. Valid paths are preserved. Shell completion cannot inspect Python or Jupyter runtime objects. While On, unsupported syntax declines known native expansion widgets (including dot-prefixed builtins), because they can execute substitutions before completion. Other captured completion widgets retain their existing user-configured behavior and trust boundary. Off delegates the original supported Tab behavior, including any expansion it already performed.

OFF AND QUIT
Turn off Enable suggestions to stop Terminal Helper assistance and cancel a pending automatic update metadata request. Tab then delegates to the original supported shell binding; ordinary completion and third-party plugins can still do their own work. Unsafe key macros are left untouched. Open shells check state at Tab and before accepting a pending suggestion; an existing native menu may remain visible until it closes. The idle menu-bar app stays resident while Off.

Disable and Quit writes Off, cancels any explicitly started update, terminates owned integration and update worker groups, waits for them to exit, and then closes the controller. Update cancellation allows time to detach the disk image and clean up validation work. The updater's own external quit request also writes Off and stops integration workers, while allowing that explicitly approved update process to finish replacing and reopening the app. Missing or malformed state leaves assistance disabled. You can keep using the shell normally.

UPDATES
Check for updates automatically is enabled by default in Settings. While suggestions are On, the app checks GitHub at a normal launch or when you enable suggestions, at most once every 24 hours from the last attempt. There is no timer: if you keep the app running, the next eligible check happens when you enable suggestions again or relaunch. No automatic request runs while suggestions are Off. Turning suggestions Off, disabling the checkbox, or quitting cancels a pending automatic check and ignores late responses.

A new-version notice offers Update Now, Remind Me Later, and Skip This Version. Update Now starts the existing download and verified installation flow. Remind Me Later dismisses the notice until the next eligible daily check; a clickable version offer stays in the menu. Skip This Version suppresses automatic notices for that exact version, while a newer version can still be offered.

Check for Updates in the menu bar or Settings is always an explicit action, even while suggestions are Off. It ignores the skipped version and daily throttle, and records its attempt so an automatic check does not immediately repeat a reminder. The current version is shown in both places. Automatic connection errors stay inline instead of opening an error alert; use the manual action to retry.

When a newer published release exists, Update Now downloads the disk image and verifies its published checksum. Choose Install Update to approve in-place installation. A short-lived process from the current app validates the update before asking the controller to quit. It turns suggestions Off, replaces the app in the same location, updates the owned shell integration, and asks macOS to reopen Terminal Helper. Shell integration installation or removal must finish before an app update can start.

Restart open terminal shells after the update, then enable suggestions again. The updater preserves quarantine and does not change macOS security settings, remove security attributes, or request administrator privileges. Because this beta is ad-hoc signed and not notarized, macOS may require your approval to reopen it; use Apple's per-app process above only if you trust the download.

If installation cannot complete, the updater reports a safe error. A recovery copy of the old app and RECOVERY.txt are kept in a private sibling .Terminal-Helper-update-<UUID> folder beside the installed app. Follow those recovery instructions if reopening fails. An update cannot write a location you do not have permission to change.

You can also use terminal-helper version, terminal-helper check, and terminal-helper update after installing the current shell integration. The update command downloads, verifies, and installs the latest newer published release; it can close the running controller and reopen the updated app. Run it only when you are ready to update.

TROUBLESHOOTING
If Enable suggestions is unavailable, install or update shell integration first and wait for it to finish. When an installed script differs from this app's bundled version, Update shell integration is the primary action. Off remains available even when the integration is outdated.

If nothing appears after Tab, open a new terminal window and check that you are running interactive zsh. The menu reports whether the integration file exists; it cannot verify which already-open shells loaded it. Use Repair shell integration when needed.

Custom ZDOTDIR: choose the folder containing your actual .zshrc. The app does not evaluate .zshenv or other shell configuration to discover it. You can choose a different folder during installation, repair, or uninstall.

Installation failures: check that your configuration folder belongs to you and is writable. Symlinked or unsafe configuration is rejected. Your existing .zshrc is never overwritten as a whole; the installer uses a narrow, marked block and makes a backup. Existing user-configured completion code runs with your user privileges.

If an interrupted installation reports that another operation is in progress, first ensure no install or uninstall is still running. A forced Quit can leave an empty lock folder. Remove only that empty folder with this command, then retry:

rmdir "$HOME/Library/Application Support/Terminal Helper/.integration-lock"

rmdir refuses to remove a nonempty folder. Do not delete other Terminal Helper files as lock recovery.

UNINSTALL
Choose Uninstall shell integration in Settings and use the same configuration folder. Restart open terminal shells, choose Disable and Quit, then remove Terminal Helper from Applications. Keep any configuration backup you want to retain.

PRIVACY AND COMPATIBILITY
No command history, command buffers, environment contents, or filenames are logged or uploaded. Enabled automatic update checks and explicit update checks or downloads contact GitHub. Automatic metadata checks run only at the launch/enable boundaries and interval described above. The automatic-check preference, last attempt date, and skipped version are stored locally; no command data is stored for update notices. There is no cloud AI, telemetry, global keyboard monitoring, or background indexing. No Accessibility or screen-recording permission is needed.

The free beta targets macOS 13 or later on Apple silicon and Intel. Automated macOS runner tests are documented separately; physical Terminal.app and iTerm2 behavior needs the documented manual verification. Ad-hoc beta builds are not Developer ID signed or notarized. Use only Apple's per-app process described above when you trust the download; managed Macs may restrict this option.

DIAGNOSTICS
Run terminal-helper doctor in the affected interactive shell. It reports app metadata separately from this shell's loaded integration, shared state and current keybinding ownership. It does not repair configuration, collect history or print environment values. If a later plugin replaced Tab, keep that binding or adjust plugin loading order deliberately; restart shells after integration updates.
